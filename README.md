Callista Mayer Chan — Personal Portfolio Website

1. Project Description

This project is a personal portfolio website created to introduce myself, share my interests, and showcase my experiences as a Computer Science student at BINUS University.

The website uses a soft pink aesthetic, rounded cards, decorative elements, and emoji icons to create a simple, friendly, and visually appealing user experience.

2. Technologies Used

- **HTML5** — Structures the website content and sections.
- **CSS3** — Styles the layout, colors, typography, animations, and responsive design.
- **JavaScript** — Adds interactivity by highlighting the active navigation link based on the current scroll position.
- **Google Fonts** — Provides decorative and readable typography.
- **Emoji icons** — Represent personal interests without requiring external icon libraries.

3. Website Structure

The website consists of the following sections:

A. Navigation Bar
- Contains links to Introduction, About Me, and Portfolio.
- Uses anchor links to navigate between sections on the same page.
- Stays visible at the top while scrolling.
- Highlights the navigation link corresponding to the current section.

B. Hero / Introduction
- Displays my name, Callista Mayer Chan.
- Includes a background photograph with decorative pink lettering layered over it.
- Introduces me as a sophomore Computer Science student at BINUS University.
- Includes an "Explore My Work" button that navigates to the Portfolio section.

C. About Me
Contains three cards describing my interests and personal background:

1. **A Tri-Lingual** — Introduces the languages I speak: Chinese, English, and Indonesian.
2. **Caffeine Enthusiast** — Describes my interest in coffee, matcha, and tea.
3. **Trying to Be Sporty** — Shares my interest in working out, basketball, and swimming.

Emoji icons are used to make the cards visually engaging and easy to customize.

D. Past Experiences / Portfolio
Contains two experience cards:

- **Tutoring Friends** — Describes my experience helping friends study during examination periods.
- **Building Programs** — Describes my programming experience, particularly through AOL projects.

E. Footer
Displays a simple closing message with decorative heart symbols.

5. How to Run the Website:

a. Download or clone the project folder.
b. Open the folder in Visual Studio Code.
c. Ensure all project files, including `hero-photo.jpg`, are in the correct locations.
d. Open `mainPage.html` in a web browser.
e. Navigate through the website using the navbar or the "Explore My Work" button.

An internet connection is required to load the Google Fonts used by the website. The website's basic layout and functionality can still work without them.

6. Design and User Experience

The website uses a pastel pink and brown color palette to create a consistent visual identity.

Design features include:

- Rounded cards with soft shadows.
- Decorative pink lettering and a photo overlay.
- Emoji icons for simple visual communication.
- Hover effects on cards and buttons.
- Smooth scrolling between sections.
- A sticky navigation bar for easier access to each section.
- Responsive layouts for desktop and smaller screens.

These features aim to make the website easy to navigate while maintaining a consistent and personal design.

7. Responsiveness

CSS media queries are used to adapt the website to different screen sizes.

On smaller screens:

- The introduction layout changes to a single-column layout.
- About Me cards stack vertically.
- Past Experience cards adjust to the available width.
- Navigation spacing and text sizes are reduced to fit smaller displays.

This helps maintain readability and usability across desktop and mobile devices.

8. Interactivity

The website includes several interactive features:

- **Navigation links:** Scroll to the relevant page section.
- **Active navigation state:** JavaScript highlights the navbar link associated with the current scroll position.
- **Explore My Work button:** Navigates to the Portfolio section.
- **Card hover effect:** About Me cards move slightly upward when hovered over.
- **Button hover effect:** The Explore My Work button shifts slightly when hovered over.
- **Smooth scrolling:** Makes navigation between sections feel more natural.
